## 3. Fusion

### Unit tests T1–T8

`backend/tests/test_fusion.py` asserts the exact expected values of section 8.4 (±0.5 on scores, ±0.01 on evidence) plus a test that the fusion function has no weather parameter. Run: `cd backend && pytest -q`.

### Ablation over the 40 simulated incidents

Default band counts: {'Critical': 2, 'High': 5, 'Moderate': 9, 'Low': 24}

| Variant | Description | Band changes | Kendall τ (all) | Kendall τ (top-10) | Mean score shift |
|---|---|---|---|---|---|
| (a) flat mean | 100 x mean of S_v and S_n present; no confidence, reliability or modality weights | 0 | 0.865 | 0.956 | -0.50 |
| (b) no reliability | all source reliabilities set to 1.0 | 0 | 0.898 | 0.956 | +0.22 |
| (c) no renormalization | missing modality counted as S = 0 with its full modality weight | 6 | 0.664 | 0.600 | -6.37 |
| (d) weather at 30% | 0.7 x priority + 30 x W, constant city reading {'rainfall_mm': 42.0, 'wind_kmh': 55.0, 'humidity': 90.0} -> W = 0.65 | 13 | 1.000 | 1.000 | +9.52 |

### Notes

- No ground-truth priority exists; these numbers describe behaviour and stability, not accuracy.
- Kendall tau is tau-b (ties handled) between the variant's and the full rule's priority scores.
- Scaling every reliability by the same factor leaves priorities unchanged (it cancels in the ratio); only the 1.0 cap on x1.2 changes relative influence, which is why x0.8 gives tau = 1.
- Weather is identical for every incident in the city, so (d) shifts all scores together; its band changes show what adding it would do, not a better ranking.
